## Overview

Auto GPU Switcher is the intelligent GPU switching subsystem for ArchTitan OS. It automatically switches between integrated and discrete GPUs based on workload, power state, and thermal conditions — integrating with THM (Titan Hardware Manager) for sensor data.

## Planned Features

- Automatic iGPU / dGPU switching (PRIME / optimus)
- THM integration for thermal-aware switching decisions
- Waybar status widget
- Manual override support
- Power profile integration
