# Security Policy

## Supported Versions
Only the latest revision of the `main` branch receives active security updates and patches.

## Reporting a Vulnerability
If you discover a security vulnerability or exploit within ArchTitan OS or its daemons:
* **Do NOT report security vulnerabilities via public GitHub Issues.**
* Please submit a private advisory through the **Security** tab (`Security` -> `Advisories` -> `Report a vulnerability`) or contact the maintainer directly.

All valid reports will be investigated and addressed promptly before public disclosure.
