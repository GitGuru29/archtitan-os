1. Project Overview
ArchTitan OS is a developer-focused custom Linux distribution built on Arch Linux. It targets 8–16
GB RAM devices and is designed to be the primary OS for software developers — specifically
Android, Web, and Systems programmers. The OS centers around three core philosophies:
1. Low overhead — Idle RAM usage < 1 GB. Background processes are managed
intelligently, not blindly killed.
2. Context awareness — The OS understands what the user is doing and adapts resources
accordingly in real time.
3. Integrity — The session stack (Hyprland + SDDM) is enforced at 4 security layers. No
competing DM/DE can take over.

4. Titan Hardware Manager (HWM)
The HWM is the defining feature of ArchTitan. It is a C++17 multi-threaded daemon (~575 lines)
that monitors the Hyprland compositor in real time and surgically manages system resources based
on what the user is doing.

4.7 Debounce (Anti-Flicker)
Rapid window switching generates many events. Without debounce, switching from a terminal to a
browser and back would trigger 2–3 full profile transitions in under a second.
sequenceDiagram
participant HY as Hyprland
participant SC as schedule()
participant TH as Thread (gen=N)
participant TR as do_transition()
HY->>SC: activewindow>> code (gen→1)
SC->>TH: Spawn thread gen=1, sleep 800ms
HY->>SC: activewindow>> firefox (gen→2)
SC->>TH: Spawn thread gen=2, sleep 800ms
Note over TH: gen=1 thread wakes, checks gen counter
TH-->>TH: debounce_gen=2 ≠ 1 → EXIT (stale)
HY->>SC: activewindow>> code (gen→3)
SC->>TH: Spawn thread gen=3, sleep 800ms
Note over TH: gen=2 thread wakes → EXIT (stale)
Note over TH: gen=3 thread wakes → gen=3 ✅ FIRE
TH->>TR: do_transition(WEB_DEV)

6. CLI Tool — titan-hwm
A native C++ binary (no shell, no socat, no external dependencies) that communicates directly
with the daemon via UNIX domain socket.

CLI->>CLI: stat() socket — exists?

7. Waybar Integration
The HWM Waybar module (titan-hwm-waybar) polls the state file every 5 seconds and
returns a JSON blob that Waybar renders as a profile pill with per-profile colour coding.
